WP Contact Manager

WP Contact Manager is a custom WordPress plugin that stores and manages contact form submissions securely inside the WordPress admin dashboard.

🚀 Features
- Creates a custom database table on activation
- Displays contact submissions in WordPress admin
- Secure output using WordPress escaping functions
- Clean and modular plugin structure

## 🛠️ Tech Stack
- PHP
- WordPress
- MySQL
- HTML & CSS

📂 Plugin Structure

wp-contact-manager

├── wp-contact-manager.php

├── README.md

└── includes/

└── admin-page.php


📥 Installation
1. Clone this repository
2. Upload the folder to `/wp-content/plugins/`
3. Activate **WP Contact Manager** from WordPress Admin
